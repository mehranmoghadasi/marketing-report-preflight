# Example data

Everything under `clients/northgate-plumbing/` is **synthetic**. There is no such company,
no client data is involved, and none of the numbers describe real campaign performance.
They were generated by `make_example_data.py` to exercise every check:

- **2026-07** — a clean month: all 31 days present, nothing unusual.
- **2026-08** — the interesting month. The export stops on the 28th, GA4 reports truncated
  data from the 29th and an 82% sample, call tracking records zero for the whole month,
  the consent denial rate jumps from 22% to 34%, indexed URLs fall 8.1%, and 6 of 229
  conversion rows are duplicates.

Running August therefore produces 3 failing checks, 5 warnings and 2 passes, and the
verdict *Do not send yet*.

```bash
bash demo.sh                    # from the repo root: bash examples/demo.sh
python make_example_data.py     # regenerate the synthetic data
```

`output/` holds the artefacts of that run — `preflight.json`, `preflight.html` and
`data-notes.md`. They are committed and are produced by the tool, not written by hand:
`tests/test_api_and_reproducibility.py` fails if they drift from a fresh run, and the CI
workflow runs the demo and then `git diff --exit-code` on this folder.

Running the July period will not work out of the box, because it would need June data as
the previous period. Add `data/2026-06/` if you want to try it.
